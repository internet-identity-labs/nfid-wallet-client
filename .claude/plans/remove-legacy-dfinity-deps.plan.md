## Implementation Checklist

### Build config

- [x] Add the four aliases to the `config.resolve.alias` block in
      `apps/nfid-frontend/webpack.config.js`. They point at the bare specifier
      (`"@icp-sdk/core/agent"`), not a `require.resolve` path, so webpack picks the ESM build
      through the package's own exports map instead of the CJS one `require.resolve` returns.
- [x] Add matching `paths` to `tsconfig.base.json`. First written as `.../index.d.ts`, which
      broke the build — `TsConfigPathsPlugin` reads the same map and fed webpack a
      declaration file. Corrected to extension-less `.../index`.

## Runtime smoke test

`@nfid/vaults` loaded with `@dfinity/agent` redirected to `@icp-sdk/core/agent`, driven
against `4bgdx-hqaaa-aaaar-qaeqq-cai` (`NFID_VAULT_MANAGER_CANISTER_ID` from `.env.ic`):

- query `get_version` → `Reject code: 5 … Canister has no query method 'get_version'`.
  Actor construction, IDL encoding, transport and response decoding all worked; the canister
  is the manager, not a vault, so the method is genuinely absent.
- update `execute`, signed by a generated `Ed25519KeyIdentity` →
  `Canister has no update method 'execute'`. The replica verifies the request signature
  before it resolves the method name, so reaching a method-not-found rejection proves
  `transformRequest` and the certificate handling work across the swap.

Script: `scratchpad/vault-bridge-smoke.cjs` (not committed).

## Risks & Notes

- Baseline on this branch before any edit: `yarn install --frozen-lockfile` clean,
  `tsc -p apps/nfid-frontend/tsconfig.app.json` clean, `nx build nfid-wallet-client` exit 0.
  `tsc -p packages/integration/tsconfig.lib.json` fails on a pre-existing TS6307 (the
  package's own tsconfig does not list `packages/config` / `packages/client-db`) — not caused
  by and not addressed here.
- Node must be 22.18.0 (`.nvmrc`); yarn refuses to install on 22.10.0.
- Not covered by any of the above: a vault update call that the canister actually accepts,
  which needs a registered member identity and a real vault. The smoke test proves the
  signature is accepted by the replica, not that a vault authorizes it — that part of the
  flow is independent of the agent version.
